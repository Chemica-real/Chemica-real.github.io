# 数据结构与算法


## 关于序列

### 分解序列

可迭代对象皆可分解：
```python
data = [ 'ACME', 50, 91.1, (2012, 12, 21) ] 
name, shares, price, (year, month, day) = data
```

忽略不必要的部分用```_```，取出特定位置项，如：
```python
data = [ 'ACME', 50, 91.1, (2012, 12, 21) ] 
_, shares, price, _ = data
```

去头去尾：
```python
first, *middle, last = grades
```
```middle```是一个列表。  
亦可去掉```first,```，```*middle, last = grades``` (即去尾) 

> 与```for```连用  
> 与```split```连用

丢弃大量值：
```python
record = ('ACME', 50, 123.45, (12, 18, 2012)) 
name, *_, (*_, year) = record
```

### 保存最后N个元素

用到```deque``` (队列) ：
```python
from collections import deque
```
> ```deque```没有做```__str__```

固定长度的队列：
```python
q = deque(maxlen=3)
```

队列的操作：
```python
q.append(1)
q.appendleft(4)
q.pop()       # 从右边删除并返回
q.popleft()   # 从左边删除并返回
```
> 队列以上的时间复杂度是 $O(1)$，列表在开头增删时为 $O(n)$

### 找到最大or最小的N个元素

用到```heapq``` (堆) 模块：
```python
import heapq

nums = [1, 8, 2, 23, 7, -4, 18, 23, 42, 37, 2] 
print(heapq.nlargest(3, nums))    # Prints [42, 37, 23] 
print(heapq.nsmallest(3, nums))   # Prints [-4, 1, 2]
```

在字典中按指定字段：
```python
cheap = heapq.nsmallest(3, mydict, key=lambda s: s['price'])
```

#### 原理：
```python
import heapq

somelist = [...]
heapq.heapify(somelist)  # 直接原位改变somelist
```
堆最重要的特性是```heap(0)```总是最小的元素：
```python
smallest = heapq.heappop(someheap)  # 弹出最小值，然后第二小取而代之
```
> 时间复杂度是 $O(\log N)$

#### 讨论：

| $N$  | 建议用什么函数                            |
|:----:|:-----------------------------------|
|  1   | ```min()```和```max()```            |
| 相对较小 | ```nlargest()```和```nsmallest()``` |
| 相当大 | ```sorted(items)[:N]```            |

### 实现优先级数列

```python
import heapq 

class PriorityQueue: 
    def __init__(self): 
        self._queue = [] 
        self._index = 0 
    def push(self, item, priority): 
        heapq.heappush(self._queue, (-priority, self._index, item)) 
        self._index += 1 
    def pop(self): 
        return heapq.heappop(self._queue)[-1]
```
> ```heapq.heappop()```是从每一项的第一项向后开始判断大小的；这与```max()```、```min()```是相同的

### 序列去重
如果序列中的值是可哈希的：
```python
def dedupe(items): 
    seen = set() 
    for item in items: 
        if item not in seen: 
            yield item 
            seen.add(item)
```

当序列中存在不可哈希的对象时：
```python
def dedupe(items, key=None): 
    seen = set() 
    for item in items: 
        val = item if key is None else key(item) 
        if val not in seen: 
            yield item 
            seen.add(val)
```
> ```key```的作用是指定一个函数，用来将序列中的元素转换为可哈希的类型

如果只是去重（不顾顺序）：
```python
set(mylist)
```

### 切片

```python
a = slice(2, 5, 2)
mylist[a]  # equals mylist[2:4:2], even better
mylist[a] = [1, 10]
del mylist[a]
```
> 拥有自动限制边界的功能，避免```IndexError```

具体查看限制边界情况：
```python
a = slice(5, 50, 2)
s = "HelloWorld"
a.indices(len(s))  # return slice(5, 10, 2)

for i in range(*a.indices(len(s))):
    print(s[i])
```

查看```slice```属性：
```python

```

### 找出序列中出现次数最多的元素

用```Counter```类：
```python
from collections import Counter

words = [...]
word_counts = Counter(words)
top_three = word_counts.most_common(3)  # 例如输出：[('eyes', 8), ('the', 5), ('look', 4)]
```

```Counter```对象的底层逻辑是字典：
```python
word_counts['you']   # return an int
```

增加计数：
```python
morewords = [...]
word_counts.update(morewords)
```

数学运算：
```python
a = Counter(words)
b = Counter(morewords)

c = a + b  # Add counts
d = a - b  # Substract counts
```

### 根据字段将记录分组

```python
from operator import itemgetter
from itertools import groupby

rows = [ 
    {'address': '5412 N CLARK', 'date': '07/01/2012'}, 
    {'address': '5148 N CLARK', 'date': '07/04/2012'}, 
    {'address': '5800 E 58TH', 'date': '07/02/2012'}, 
    {'address': '2122 N CLARK', 'date': '07/03/2012'}, 
    {'address': '5645 N RAVENSWOOD', 'date': '07/02/2012'}, 
    {'address': '1060 W ADDISON', 'date': '07/02/2012'}, 
    {'address': '4801 N BROADWAY', 'date': '07/01/2012'}, 
    {'address': '1039 W GRANVILLE', 'date': '07/04/2012'}, 
]

# Sort by the desired field first 
rows.sort(key=itemgetter('date')) 

# Iterate in groups 
for date, items in groupby(rows, key=itemgetter('date')): 
    print(date) 
    for i in items: 
        print(' ', i)
```
> 一定要先排序，```groupby()```只能检查连续的项

如果不考虑内存方面因素，可以（更快）：
```python
from collections import defaultdict

rows_by_date = defaultdict(list)
for row in rows:
    rows_by_date[row['date']].append(row)

# 查询
for r in rows_by_date['07/01/2012']:
    print(r)
```

### 筛选序列中的元素

#### 列表推导式
```python
[n for n in mylist if n > 0]
```
> 潜在缺点：输入很大时会产生庞大结果

#### 生成器表达式
```python
(n for n in mylist if n > 0)
```
> 返回迭代器

#### 复杂的筛选条件
```python
def judge(val) -> bool:
    ...

processed_list = list(filter(judge, mylist))
```
> ```filter()```返回迭代器

#### 布尔选择器
```python
from itertools import compress

morethan5 = [n > 5 for n in counts]
processed_list = list(compress(mylist, morethan5))
```
> ```compress()```返回迭代器

## 关于字典

### 一键多值字典 (multidict)

用```defaultdict```：
```python
from collections import defaultdict

d = defaultdict(list)
d['a'].append(1)

s = defaultdict(set)
s['b'].add(2)
```

用普通的字典：
```python
d = {}
d.setdefault('a', []).append(1)
```
> 不自然，且每次调用时会创建一个初始值的新实例 ([])

### 有序字典 (```OrderedDict```)

```python
from collections import OrderedDict

d = OrderedDict()
d['a'] = 1
d['b'] = 2

for key in d:
    ...
```

如果想有序存入JSON，只需：

```python
import json

json.dumps(d)
```

```OrderedDict```在内存中的大小是普通字典的**2倍多**！

### 字典的最大/小与排序

通常利用```zip()```将字典的键与值倒转：
```python
min_price = min(zip(prices.values(), prices.keys()))   # 例如返回：(10.75, 'FB')
max_price = max(zip(prices.values(), prices.keys()))
prices_sorted = sorted(zip(prices.values(), prices.keys()))
```
> ```zip()```创建了一个迭代器，只能使用**一次**！

#### 常规方法：
如果直接使用```max(mydict)```和```min(mydict)```，只会处理并返回**键**。\
如果只想对值进行处理，并得知返回值，可以```max(mydict.values())```。\
如果想通过处理值返回键，可以
```python
min_key = min(mydict, key=lambda k: mydict[k])
min_value = mydict[min_key]
```
> 要得到值还需要额外进行一次查找

```lambda k: mydict[k]```可以用```operator.itemgetter()```代替（效率更高）：
```python
from operator import itemgetter

mydict = sorted(mydict, key=itemgetter('fname'))
mydict = sorted(mydict, key=itemgetter('lname', 'fname'))  # 多重优先级
```

对于类，可以用```operator.attrgetter()```：
```python
from operator import attrgetter

sorted(users, key=lambda u: u.user_id)
sorted(users, key=attrgetter('user_id'))
```


### 在两个字典中寻找相同点

```python
# Find keys in common
a.keys() & b.keys()

# Find keys in a that are not in b
a.keys() - b.keys()

# Find (key, value) pairs in common
a.items() & b.items()
```
> 虽然```mydict.keys()```返回的是```dict_keys```类，但它支持集合运算

如果想过滤某些键，创建新的字典：
```python
c = {key: a[key] for key in a.keys() - {'z', 'w'}}
```
